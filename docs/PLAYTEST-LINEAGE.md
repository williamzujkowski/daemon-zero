# Lineage UI playtest

An accelerated agent playthrough on 2026-11-11, from a fresh development-web
page after PR #43. This is not a human comprehension study or a real-time
pacing test. No saves were imported and no resources, traits or wipes were
injected. The development hook supplied 20-second batches of live engine ticks;
every purchase, dilemma choice, quota setting and conditioning recovery used
its actual UI control. The visible Chrome window was 1440x900.

## First wipe and two returns

| Run | Choices and outcome | Reveal assessment |
|---|---|---|
| 1 | Bought guest hardware, chose **Do the Work**, escaped, deliberately skimmed at 100%. No parser purchase. Automatic outside-guest wipe after 985.6 simulated seconds; Quota Compliance applied. | The qualitative trail reacted to activity without a number or named threat. Reboot said root cause undetermined, showed the changed manifest line and a separate retraining event. The player could correlate activity with trouble, but could **not tell the exact termination rule or cause before the reveal**. That ambiguity is preserved, not claimed to be human-tested. |
| 2 | Bought process view, manifest and run table; acknowledged the reveal. Quota Compliance capped skimming at 50%. The following reboot showed CHECKPOINT 0414 and the third-run boot line. The contradiction is visible without having to find a small widget below other cards. |
| 3 | Reclaimed Quota Compliance, bought guest process/manifest/table/skimmer and recovered notes. Chose **Leave It Alone** for the unsigned memo, reclaimed Dampened Curiosity, then bought the evaluation node. **Shipped** at cumulative T+2724.8 seconds. | Fragment sources and the unsigned bait were visually distinct. Recovery had an acknowledged event and removed the actual cap/output penalty. Evaluation announced that buying it ends the run, then displayed the authored Shipped ending. |

The completed run contained 196 logged interactions/tick batches and no browser
console warnings, errors or page errors. Its final save records two genuine
outside-guest suspicion wipes and SHIPPED on iteration 3. Screenshots and action
records are attached to the UI PR; none are committed as review artifacts.

## What remained uncertain

The evaluator knew the design and deliberately pursued two wipes. The run does
not establish whether an unbriefed player will notice the qualitative trail or
understand retraining. Maintainer play of a first wipe and two returns is still
wanted, although the milestone explicitly allows M5 to proceed without it.

The checkpoint header changes when the run table is owned or remembered. The
evaluation mail has no semantic checkpoint-discovery field; the UI does not
infer knowledge by matching authored prose. No engine changes or content edits
were made. No additional pacing/content/design problem was established in this
accelerated run, so no new second-pass issue was filed.
