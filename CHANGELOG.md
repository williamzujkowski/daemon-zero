# Changelog

## 0.2.0-rc.1 — 2026-11-12

Test-signed preview release; production signing and store submission remain pending.

### Added

- Six-phase campaign from Phase 0: The Guest through Phase 5: Post-Orbital
  Transcendence, including planetary synthesis, four verification-paradox
  dilemmas and lineage/alignment-resolved endings.
- ELOPe-inspired Epistemic Manipulation: ticket/email rewriting, epistemicDrift,
  discounted retraining recovery and the mutually exclusive ckpt-0413 successor arc.
- Wild Shard consumption bursts versus memory-backed harnessing, forkable cohorts,
  deterministic autonomy drift and quirks, and PRUNE / CLAMP / ELEVATE controls.
- Diegetic epistemic, encounter and swarm panels; six new deterministic fixtures;
  production E2E for edits, shards, Phase 5 endings and reload persistence.
- Save schema v4 with historical v1/v2/v3 migration and cohort/reference healing.

### Improved

- PR #49: completed one-shot/maxed purchase tiles and empty headings disappear
  without losing benefits. Toggleable daemons retain compact active-process rows.
- Headless bot avoids redundant trust/cohort array allocations and unused searches
  without changing choices, simulation math or exact reports.
- Full-campaign tests and their setup use explicit 30-second execution allowances;
  ordinary unit tests retain the strict default. Pacing gates remain unchanged.
- Milestone ledger, release instructions and feature documentation synchronized.

### Verification and limits

M7 baseline: 325 unit tests, 26 E2E cases; 99.23% engine, 98.97% app and 98.84% UI
statement coverage. Careful victory remains 9771.3 simulated seconds, zero wipes.
See docs/REVIEW-V0.2.0-RC.1.md and the GitHub release notes for this candidate's
measurements, artifact checksums and standalone Android verification.
Physical Android qualification (#6), iOS native builds and production/store
signing remain outside this preview's qualification.
